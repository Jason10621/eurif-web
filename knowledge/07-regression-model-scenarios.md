# 다중선형회귀 모형·β 계수·시나리오

## 분석 모형
```
Y = β₀ + β₁·(블루라이트 노출 시간) + β₂·(카페인 잔류 농도) + β₃·(수면 부채 누적량) + ε
```
- Y = 수면 위상 지연량(분) = 당일 취침 시각 − 개인 기준 취침 시각
- ε = 오차항
- 공변량: 크로노타입(MEQ 5단계, −90 ~ +90분), 운동 여부, 수면유도제 옵션

## 모듈이 구현한 β 계수 (선행 연구 기반 스케일링, 예상값)
| 계수 | 값 | 의미 | 근거 |
|---|---|---|---|
| β₁ | **0.18** | 블루라이트 조정 노출 1분당 위상 지연(분) | Czeisler 2006, 전윤서 파트 청소년 취약성 |
| β₂ | **0.22** | 카페인 혈중 잔류 1mg당 위상 지연(분) | Drake 2013 "250mg → 40분 지연" 스케일링, 홍서준 파트 |
| β₃ | **0.045** | 수면 부채 누적 1분당 위상 지연(분) | Roenneberg 2003 MSFsc, 이정욱 파트 |

표준화 β* 계산용 SD 참조값: **SD_BL = 35분, SD_CAF = 60mg, SD_DEBT = 150분** (Buysse 1989 PSQI 가중치 참조).

※ 이 β 값들은 실제 데이터 수집·분석(Phase 5) 전의 **예상 계수**다. 실제 회귀 분석 결과가 나오면 갱신한다.

## 회귀 지표 해석

### 회귀계수 β
"다른 변수를 고정했을 때 해당 변수 1단위 증가가 Y를 얼마나 변화시키는지". 블루라이트는 분 단위, 카페인은 mg 단위라 원래 β끼리는 직접 비교 불가.

### 표준화 β* (베타)
각 변수의 표준편차로 나눠 같은 단위로 환산한 값. "세 변수 중 누가 가장 센지" 순위를 알려준다.

### R² (결정계수)
"이 모형이 현실을 얼마나 잘 설명하는가"의 비율(0~1). 0.3 이상이면 의미 있는 설명력. 변수를 무조건 늘리면 R²는 항상 올라가므로, 표본 수(n)와 변수 수(k)를 함께 고려한 **조정 R²**로 보정한다. 모듈에서는 조정 R² 추정: `0.30 + 0.52 × (설명 분산 / 최대 가능 분산)`.

### p-value
통계적 유의성. < 0.05면 해당 변수의 효과가 우연이 아님.

### VIF (분산팽창지수)
다중공선성 지표. < 5 권장, < 2 이상적. 모듈 예시값: VIF X1 = 1.12, X2 = 1.08, X3 = 1.19 → 세 변수가 동시에 대입되어도 서로 독립적으로 Y에 영향(다중공선성 없음). 이것이 "독립적 기여도"의 의미 — 블루라이트를 올려도 카페인·수면부채 항은 그대로 유지된다.

## 결과 해석 시나리오

### 시나리오 A — 블루라이트가 가장 강한 예측 변수 (β*₁ 최대)
- 해석: 수면 위상 지연 개선을 위해 가장 우선적으로 취침 전 스마트폰 사용을 줄여야 한다.
- 정책 제언: 야간 디지털 기기 사용 제한, 야간 모드(Night Mode) 의무화.

### 시나리오 B — 카페인이 가장 강한 예측 변수 (β*₂ 최대)
- 해석: 오후 시간대 카페인 섭취 절제가 수면 개선의 핵심 개입 지점.
- 정책 제언: 학교 매점·자판기의 오후 6시 이후 에너지드링크 판매 제한.

### 시나리오 C — 통합 모형 R²가 개별 모형보다 유의미하게 높음
- 해석: 단일 변수가 아닌 복합적 행동 패턴이 수면 위상 지연을 결정한다.
- 정책 제언: 수면 교육 프로그램에서 '블루라이트 + 카페인 + 수면 스케줄'을 통합적으로 다뤄야 한다.

## 회귀 분석 단계 (실험계획서 §5-3)
| 단계 | 내용 | 산출물 |
|---|---|---|
| 단순 모형 3개 | X₁만, X₂만, X₃만 각각 회귀 | 개별 R², β, p-value |
| 통합 모형 | X₁+X₂+X₃ 동시 투입 | 전체 R², 조정 R², 각 β* |
| 단계적 회귀 | 유의하지 않은 변수 제거 (p > 0.1) | 최적 예측 변수 조합 |
| VIF 점검 | 모든 독립변수 VIF 계산 | 다중공선성 진단 |
