## 남은 실험 단계

### 실험 준비
- 조원끼리 진행하더라도 참여 동의서 필요
- 스마트폰 기종 확인 (iOS 스크린타임 / 안드로이드 디지털 웰빙 활성화) — 아이폰·삼성 기기 모두 필요
- 모듈 기반 변수에 대한 일별 설문조사 응답
- 카페인 함량 참고표 인쇄 배포 (6종 음료 mg 기준표)
- 일별 설문 폼 6문항, 응답 소요 3분 이내 확인

### 생활-수면조사 절차 반복 (2주)

### 데이터 정제 (이정욱 담당)
- 이상치 제거: Z-Score 판별식 (|Z| > 3.0 → 제외). 적용 변수: 블루라이트 0~480분, 카페인 0~1,000mg, 수면 부채 0~3,000분, 취침 시각 지연 ±180분.
- 개인 기준 취침 시각 산출: 2주 평균 취침 시각 → Y(지연량) 계산 기준선 확정.
- MSFsc 최종 산출: 주말 취침·기상 데이터로 계산 → X₃ 검증.

### 통계 분석 (각자 진로 연계)
- 기술통계: 평균·표준편차·최솟값·최댓값, Shapiro-Wilk 정규성 검정, 히스토그램·박스플롯.
- 상관분석: 피어슨/스피어만 상관계수, 상관행렬 히트맵으로 다중공선성 예비 점검(r > 0.8 주의).
- 다중선형회귀(메인): 단순 모형 3개 → 통합 모형 → 단계적 회귀 → VIF 점검.
- 분석 도구: 1차 엑셀 데이터 분석 추가기능(팀 전원, 각자 조사한 이론 바탕), 2차 Google Colab Python (pandas + statsmodels, 이정욱 담당).

### 결과·결론 해석 + 시나리오 분류 (핵심)
- 모의로 작성한 것이니 실제 결과 나온 대로 '방향성'만 유사하게.
- 시나리오 A (β*₁ 최대): 블루라이트가 핵심 원인 → 취침 전 스마트폰 제한·야간 모드 의무화
- 시나리오 B (β*₂ 최대): 카페인 섭취 시점이 결정적 → 오후 6시 이후 카페인 자제 교육
- 시나리오 C (통합 R² > 개별 R²): 복합 행동 패턴이 위상 지연 결정 → 통합 교육 프로그램
- 인과관계 주의: 관찰 연구임을 명확히 구분, 상관관계 표현 준수.

## 조원별 활동 보고서 요약

### 유가빈 (뇌과학·수면위상, 10615)
아침마다 조는 친구들의 원인이 의지 부족이 아닌 뇌과학적 원인임을 조사. N3 깊은 수면은 뇌 노폐물 청소, REM 수면은 감정 재처리. 사회적 시차가 전두엽 인지 기능 저하와 편도체 과활성화를 직접 유발. 8~9시 등교제가 저녁형 학생에게 불평등한 시스템임을 규명 → '등교 시간 유연화' 정책의 뇌과학적 당위성 입증.

### 전윤서 (생명공학, 10626)
수면 패턴을 바꾸기 어려운 원인을 유전자·분자 수준에서 파악. 생체 시계는 CLOCK, BMAL1, PER, CRY 유전자의 전사-번역 피드백 루프(TTFL)로 약 24시간 주기 작동. CRY1 변이가 수면 위상 지연의 직접 원인. 블루라이트(446~477nm)가 멜라토닌 분비를 억제해 핵심 체온(CBT) 하강을 막고 수면 개시를 지연. 청소년기 수면 위상 지연 = 약 50% 유전적 요인 + 사춘기 호르몬 변화.

### 홍서준 (약학, 10633)
학생들이 무분별하게 섭취하는 물질이 일주기 리듬에 미치는 영향을 약리학적으로 분석. 카페인은 아데노신 수용체에 경쟁적 길항제로 결합해 내인성 멜라토닌 분비를 40분 이상 늦추고 서파 수면 감소. 1세대 항히스타민 수면유도제는 반감기가 길어 숙취 효과로 기상 지연. 락티움 등 천연 보조제도 장기 복용 시 내성·반동성 불면증. 투여 타이밍·총 노출 용량·약물 내성 등 통제 변수 매트릭스 제안.

### 이정욱 (정보학, 10621, 조장)
기존 수면 연구의 한계(주관적 설문, 제한적 샘플)를 정보학적 방법론으로 보완. 오픈 API(Fitbit, HealthKit) 연동 + Python Selenium 웹 스크래핑의 하이브리드 통합 플랫폼 'Chrono-Twin' 아키텍처 설계. MCTQ MSFsc 알고리즘 이식, Z-Score 이상치 필터링 파이프라인 구축. 뇌과학·생명공학·약학 변수를 하나의 DB 스키마로 융합. 설문 응답과 Fitbit 데이터를 JSON/CSV로 병합해 매개 효과 분석 가능하게 설계.

### 윤지후 (정책, 10617)
조원들의 과학적·공학적 기전 이해를 종합해 청소년 수면 위상 문제가 제도적 폭력임을 규명. 9시 등교 정책의 실증 연구(경기도, P < 0.05)로 정책적 당위성 입증. 오전 1교시 창의적 체험활동 배치, 인간 중심 조명(HCL) 시스템 도입 제안. '아침형 인간 우월주의' 편견을 성찰하고 정부-학교-청소년 3주체의 인식 전환과 제도적 해법으로 통합적 결론 도출.
