# EURIF 실험 계획서 요약

정식 제목: "수면 위상 지연의 다중 변수 예측 모형 구축 — 블루라이트·카페인·수면 부족 누적량의 독립적 기여도 분석" (실험 5 · 다중선형회귀 분석, 2026)

## 변수 정의 및 측정 방법

### 종속변수 Y: 수면 위상 지연량
당일 실제 취침 시각 − 해당 참여자의 개인 기준 취침 시각(2주 평균값), 단위 분(min). 예: 평균 취침 시각이 오전 1:00인 학생이 당일 1:40에 잠들면 지연량 = +40분. 측정: 매일 아침 전날 취침·기상 시각을 구글 폼에 기록. 주말 데이터는 MSFsc 계산에 별도 활용.

### 독립변수 X₁: 블루라이트 노출 시간
취침 2시간 전부터 실제 취침 시각까지의 스마트폰·태블릿 사용 누적 시간(분). 측정: iOS '스크린타임' 또는 안드로이드 '디지털 웰빙' 앱의 일별 데이터 캡처 후 매일 기록. 앱 사용 불가 시 자기보고.
- TV 시청은 화면까지의 거리가 멀어 ipRGC 자극이 적으므로 제외.
- 독서등·스탠드 조명은 별도 항목으로 보조 수집(본 모형에서는 제외, 한계점에서 언급).

### 독립변수 X₂: 오후 6시 이후 카페인 총 섭취량
오후 6시 이후 섭취한 카페인 함유 음료·식품의 카페인 총량(mg). 측정: 설문지 체크리스트 방식. 항목별 섭취 여부·개수 체크 시 자동 합산.

### 독립변수 X₃: 수면 부채 누적량
조사 당일 기준 직전 5일간의 수면 부족 시간 누적 합계(분). `일별 수면 부족량 = MAX(0, 480분 − 당일 실제 수면 시간)`, 5일 합산.

### 통제변수 (공변량)
| 변수 | 수집 방법 | 통제 방법 |
|---|---|---|
| 크로노타입 | MEQ(아침형-저녁형) 설문, 사전 1회 | 회귀식 공변량으로 포함 |
| 학년 / 성별 | 초기 인구통계 설문 | 기술통계에서 그룹 분포 확인 |
| 운동 여부 | 당일 운동 30분 이상 여부 | 보조 변수, 민감도 분석 |
| 음주 여부 | 미성년 해당 없음으로 제외 | — |

## 데이터 수집 절차 (전체 흐름)
- **STEP 1 (D-7 ~ D-1) 사전 준비**: 참여자 모집·동의서, MEQ 크로노타입 설문 1회, 구글 폼 링크 배포, 스크린타임 앱 활성화 확인, 카페인 함량 참고표 배포.
- **STEP 2 (D1 ~ D7) 1주차 수집**: 매일 아침 9~11시 사이 전날 데이터 입력. D5부터 수면 부채 변수 계산 가능.
- **STEP 3 (D8 ~ D14) 2주차 수집**: 동일 절차. 주말(D7, D14) 데이터는 MSFsc 계산용 별도 마킹. 최소 10일치 완성 데이터 목표.
- **STEP 4 (D15 ~ D17) 데이터 정제**: 결측치 확인, Z-score 이상치 제거(|Z| > 3.0), 개인별 기준 취침 시각 계산, 수면 부채 변수 최종 산출.
- **STEP 5 (D18 ~ D21) 통계 분석**: SPSS/엑셀/파이썬(Colab)으로 다중선형회귀. R², β계수, p-value, VIF 산출.
- **STEP 6 (D22~) 결과 정리·발표**: 회귀 결과 해석, 한계점 논의, 연구 보고서 작성, 팀 내 공유.

## 설문지 구성
- 사전 설문 (1회, 10문항): MEQ 크로노타입 7문항, 인구통계(학년/성별) 3문항.
- 일별 설문 (매일, 6문항): 취침 시각, 기상 시각, 블루라이트 시간, 카페인 체크리스트, 운동 여부, 자유 기입. 응답 소요 3분 이내.

## 이상치 제거 기준
`|Z| = |X − μ| / σ > 3.0` → 해당 데이터 포인트 분석 제외. 적용: ① 블루라이트 노출 시간(0~480분) ② 카페인 총량(0~1,000mg) ③ 수면 부채(0~3,000분) ④ 취침 시각 지연량(절댓값 180분 초과).

## 예상 회귀 계수 방향
| 변수 | 예상 β 부호 | 근거 출처 |
|---|---|---|
| X₁ 블루라이트 | 양(+) | 전윤서 파트 — 블루라이트·멜라토닌 기전 |
| X₂ 카페인 | 양(+) | 홍서준 파트 — 카페인 아데노신 길항 |
| X₃ 수면 부채 | 양(+) | 이정욱 파트 — MSFsc 알고리즘 |

## 예상 한계점 및 보완
- 자기보고 편향 → 스크린타임 캡처 첨부로 교차 검증.
- 표본 크기 40명은 다중회귀에 충분하나 일반화 제한 → 60명 이상 확대 또는 '본교 학생 한정' 명시.
- TV·조명 블루라이트 미포함 → 추후 조도계 데이터 추가.
- 카페인 대사 속도 개인차(CYP1A2 다형성) 미반영 → 한계점 기재.
- 관찰 연구이므로 인과관계 주장 불가 → 상관관계와 인과관계 명확히 구분.

## 팀 역할 분담
- 데이터 수집 총괄: 정보학(이정욱) — 구글 폼 설계, 데이터 정제, Z-score 이상치 처리
- 블루라이트 변수: 생명공학(전윤서) — 스크린타임 기준 정의, 측정 표준화
- 카페인 변수: 약학(홍서준) — 카페인 함량표, 섭취량 환산 기준
- 수면 부채 변수: 뇌과학/수면(유가빈) — MCTQ 설문 설계, MSFsc 계산식
- 통계 분석·시각화: 정보학 + 전원
- 정책 연계: 정책(윤지후) — 회귀 결과 기반 정책 제언

(주: 실험계획서 §8의 변수별 담당 표기는 활동보고서의 파트 배정과 일부 다르며, 실제 파트 배정은 전윤서=생명공학, 홍서준=약학, 유가빈=뇌과학·수면위상이다.)
