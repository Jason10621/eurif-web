# 카페인·수면유도제·수면 보조제 약리학 (홍서준 · 약학 파트)

보고서 제목: "외부 물질과 수면의 상호작용 연구 보고서 V2"

## 카페인의 아데노신 수용체 길항 작용
- 수면 조절 = '수면 항상성 시스템'(각성 시간에 비례해 수면 압력 축적) + '일주기 리듬 시스템'의 상호작용.
- 각성 중 뇌에 아데노신이 축적 → A1, A2A 수용체에 결합 → 중추신경계 억제·졸음 유발(수면 압력).
- 카페인은 아데노신과 화학 구조가 유사 → 수용체에 **경쟁적 길항제**로 결합해 아데노신 작용 차단 → 수면 신호 차단, 각성 유지.
- 야간 카페인 섭취 → 시교차상핵 생체 시계 유전자 발현에 영향 → 내인성 멜라토닌 분비 시작을 **약 40분 이상 지연**(위상 지연 효과).
- 깊은 수면(N3, 서파수면) 비율을 유의미하게 감소시켜 수면 질 저하.

## 카페인 반감기·혈중 잔류 농도
- 반감기 t½ ≈ **5.5시간** (개인차 존재, CYP1A2 효소 유전적 다형성 관련).
- 감쇠 공식: **C(t) = C₀ × (½)^(t / t½)**
  - C₀ = 초기 섭취량(mg), t = 섭취 후 경과 시간(h)
  - 예: 오후 6시에 200mg 섭취 → 자정(6시간 후): 200 × (0.5)^(6/5.5) ≈ 94mg 잔류
- 모듈 구현: `calcCaffeineResidue(bedTimeH)` 함수, JavaScript `Math.pow(0.5, t/HALF_LIFE)`. 취침 시각이 지연될수록 잔류 농도 감소가 자동 반영됨.

## 멜라토닌 영양제 — 위상 반응 곡선(PRC)
- 멜라토닌은 직접 수면을 유도하기보다 신체에 '밤이 왔음'을 알리는 시간 조절 물질(솔방울샘 분비).
- 투여 타이밍에 따라 일주기 리듬을 앞당기거나 지연시킴:
  - **초저녁·늦은 오후 투여** → 위상 전진 → 수면 위상 지연 교정 가능(−20분, 취침 2h 전 저용량).
  - **이른 아침·새벽 복용** → 오히려 위상 지연 심화(+15분, 취침 직전 과용량).
- 복용 시간의 정밀한 통제 없는 섭취는 생체 리듬 무질서도를 높인다.

## 1세대 항히스타민 수면유도제 (디펜히드라민·독실아민)
- 약국 판매. 융기유두핵이 분비하는 히스타민(대뇌 피질 각성)을 차단해 진정 유발.
- 혈액-뇌 장벽을 높은 투과율로 통과, 히스타민 수용체에 역작용제/길항제로 작용.
- **렘수면 억제** → 수면 구조 손상.
- 반감기 **9~12시간 이상** → 다음 날 아침까지 혈중 잔류 → 졸음·무기력·인지 저하의 '숙취 효과' → 기상 시간을 늦춰 수면 위상 지연 심화(+25분).

## 천연 수면 보조제 약리 기전
- **엘-테아닌**: 녹차 아미노산. 흥분성 신경전달물질 글루타메이트와 구조 유사 → 수용체에 경쟁적 결합 → GABA 합성 촉진 → 알파 뇌파 증가.
- **GABA**: 뇌의 대표 억제성 신경전달물질. 경구 섭취 시 뇌 직접 유입 효율은 낮으나, 장-뇌 축 매개로 미주신경을 통해 간접 진정.
- **발레리안 루트(서양쥐오줌풀)**: GABA 수용체의 양성 알로스테릭 조절제. GABA 분해 효소 활성 억제로 이용 시간 연장.
- **락티움**: 우유 단백질 가수분해물. GABA 수용체에 선택적 결합 → 세포 과분극 → 교감신경 활성 저하, 코르티솔 억제.
- **마그네슘**: NMDA 수용체 통로를 전압 의존적으로 차단 → 칼슘 유입 억제 → 글루타메이트 각성 차단. 트레온산 마그네슘 형태는 뇌 전달율이 높음.
- **오남용 위험**: 장기 복용 시 수용체 하향 조절 → 내성. 갑작스러운 중단 시 반동성 불면증, 일주기 유전자 교란으로 추가 위상 지연.

## 한계점
카페인 대사 속도의 CYP1A2 유전적 다형성 미반영 → 대사 느린 군은 야간 카페인 투여 시 위상 지연이 더 급격. 개인 맞춤형 약학 제언의 발전 방향으로 제시.

## β₂ 계수 산출 근거
