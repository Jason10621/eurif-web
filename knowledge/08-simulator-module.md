# Chrono-Twin 시뮬레이터 모듈 (Experiment 5)

## 개요
ULIF 5개 파트의 자료 조사 결과를 통합해, 이론적 배경에서 도출된 수식과 계수를 직접 코드로 구현한 인터랙티브 시뮬레이터(HTML). 회귀 모형의 세 독립변수와 공변량을 입력받아 수면 위상 지연량을 실시간 산출한다.

## 구조 (가로 흐름)
입력 4개(블루라이트·카페인·수면부채·크로노타입)가 STEP 1 → 2 → 3 → 4를 거쳐 하나의 회귀 방정식으로 수렴하고, 최종 지연량이 4가지 시각화로 출력되는 구조. 각 노드 아래 채색 배지는 그 단계에서 실제 적용된 논문·이론 이름.

- **왼쪽**: 세 변수(X₁·X₂·X₃)를 각각 독립적으로 조절하면 회귀 방정식이 실시간 계산되고 예측 취침 시각이 바뀜.
- **오른쪽**: 세 변수가 총 지연량에 얼마씩 기여했는지 막대로 분해. 블루라이트를 올려도 카페인·수면부채 항은 그대로 유지 → "독립적 기여도"의 의미.

## 핵심 계산 함수 3개
1. `calcCaffeineResidue(bedTimeH)` — 취침 시각 기준 각 음료 섭취 후 경과 시간 t 계산 → `C(t) = C₀ × Math.pow(0.5, t/5.5)` 로 혈중 잔류 농도 산출. 취침 시각이 지연될수록 잔류 농도 감소가 자동 반영.
2. `calcSleepDebt()` — 5일치 실제 수면 시간(h) 입력 → 일별 `max(0, 480 − 실제 분)` → 누적 합산. Roenneberg 2003 MSFsc 보정식을 JavaScript로 이식.
3. `calcModel()` — β₁·X₁ + β₂·X₂ + β₃·X₃ + 공변량 항 → 총 지연량, 표준화 β*, R² 추정값 실시간 산출 및 테이블 갱신.

## 입력 범위 (Z-Score 이상치 기준 반영)
- 블루라이트: 0~120분 (밝기 % 슬라이더 별도)
- 카페인: 6종 음료 mg 체크리스트 (아메리카노 125 / 캔커피 74 / 에너지드링크 80 / 콜라 35 / 녹차·홍차 30~50 / 다크초콜릿 20)
- 수면 부채: 슬라이더 최댓값 5일 × 3h 부족 = 900분
- 크로노타입: MEQ 5단계 버튼(−90 ~ +90분)
- 수면유도제 옵션: "멜라토닌 취침 2h 전 저용량 → −20분", "멜라토닌 취침 직전 과용량 → +15분", "항히스타민 수면유도제(반감기 9~12h) → +25분"

## 시각화 레이어 (4가지)
1. **24시간 위상 시계** (Canvas API): 기준 수면 구간(청록색 호) vs 지연된 수면 구간(빨간색 호). DLMO 마커 표시.
2. **카페인 감쇠 곡선**: C(t) = C₀ × (½)^(t/5.5) 시간에 따른 잔류 농도.
3. **변수별 기여도 도넛 차트**: 블루라이트·카페인·수면부채 각 항이 총 지연량에 기여한 비율.
4. **수면 단계 손실 차트**: N1 5% / N2 50% / N3 17.5% / REM 22% 기준 비율, 위상 지연에 따른 N3 −0.08h·REM −0.12h/지연 1h 비대칭 손실.

## 경고 박스 (Alert Box, 3단계)
- 총 지연 > 120분: "심각한 수면 위상 지연"
- 총 지연 > 50분: "중등도"
- 총 지연 < 0분: "위상 앞당겨짐" (긍정)
- 주도 변수가 블루라이트일 때 → 시나리오 A 정책 강조. 카페인일 때 → 시나리오 B.

## 개발 단계별 흐름
1. 5개 파트 자료 조사 결과에서 계량화 가능한 수식·계수 추출.
2. 변수 정의·범위 설정 (실험계획서 §3-2 기준).
3. 핵심 함수 3개 구현.
4. 다중선형회귀 모형 적용 (β₁·β₂·β₃, 표준화 β*, R² 추정값 실시간 산출).
5. 시각화 레이어 구현.
6. 공변량 처리 (크로노타입·운동·수면유도제를 회귀식 추가 항으로 투입).
7. 이상치 방지·경고 로직 (Z-Score 기반 입력 범위 제한, 지연 수준별 Alert Box 3단계).
