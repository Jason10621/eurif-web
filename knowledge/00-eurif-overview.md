# EURIF 프로젝트 개요

## EURIF란
EURIF는 용인한국외국어대학교부설고등학교의 다학제 융합 연구 동아리다. 정보학·약학·뇌과학(수면위상)·생명공학·정책 5개 파트의 고등학생 5명으로 구성된다.

| 이정욱 | 10621 | 정보학 | 조장. 데이터 파이프라인 설계, MSFsc 알고리즘, 모듈 통합, 웹 플랫폼 |
| 홍서준 | 10633 | 약학 | 카페인 약동학, 수면유도제·보조제 약리학, 변수 통제 매트릭스 |

## 연구 주제
**수면 위상 지연의 다중 변수 예측 모형 구축** — 블루라이트 노출 시간, 오후 카페인 섭취량, 수면 부족 누적량(수면 부채)이 수면 위상 지연에 미치는 **독립적 기여도**를 다중선형회귀분석으로 검증한다.

## 연구 배경
청소년기는 생물학적으로 멜라토닌 분비 시각이 성인보다 1~2시간 뒤로 이동해 수면 위상이 지연되는 시기다. 여기에 스마트폰 블루라이트, 카페인, 학업 수면 부족이 더해지면 수면 위상 지연이 심화된다. 기존 연구는 각 변수를 개별 분석했으나, 세 변수가 동시에 작용할 때 어느 요인이 가장 강한 독립적 영향을 주는지는 고등학생 수준에서 충분히 탐구되지 않았다. 본 연구는 5개 파트 조사 결과를 통합해 학교 현장 데이터로 예측 모형을 구축하고, 가장 효율적인 개입 지점을 통계적 근거로 제시한다.

## 연구 가설
- **H1 (블루라이트)**: 취침 전 2시간 이내 스마트폰 사용 시간이 길수록 취침 시각이 늦어진다.
- **H2 (카페인)**: 오후 6시 이후 카페인 총 섭취량이 많을수록 취침 시각이 늦어진다.
- **H3 (수면 부채)**: 직전 5일간 권장 수면 시간(8시간) 미달 누적량이 클수록 주말 수면 위상이 더 지연된다.
- **H4 (통합 모형)**: 세 변수를 동시에 분석하면 단일 변수 모형보다 수면 위상 지연을 더 잘 설명한다(R² 증가).

## 회귀 모형
```
Y = β₀ + β₁·(블루라이트 노출 시간) + β₂·(카페인 잔류 농도) + β₃·(수면 부채 누적량) + ε
```
- Y = 수면 위상 지연량(분) = 당일 실제 취침 시각 − 개인 기준 취침 시각(2주 평균)
- β₁ = 0.18 (조정 노출 1분당), β₂ = 0.22 (혈중 잔류 1mg당), β₃ = 0.045 (부채 1분당)
- 공변량: 크로노타입(MEQ, ±90분), 운동 여부, 수면유도제 사용

## 연구 유형·윤리
관찰 연구(설문 기반 종단 데이터, 실험 처치 없음). 대상: 고등학생 1~3학년 40명 이상(최소 30명). 기간: 2주(14일) 연속. 참여 동의서 수령, 익명 처리, 개인 정보 별도 저장 금지, 혈액 채취·신체 측정 없음. 관찰 연구이므로 상관관계와 인과관계를 명확히 구분한다.
