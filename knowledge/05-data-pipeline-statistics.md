# 데이터 파이프라인·정제·통계 방법론 (이정욱 · 정보학 파트)

보고서 제목: "수면 위상(Chronotype) 분석을 위한 데이터 파이프라인 구축 및 웹 플랫폼 설계"

## 연구 목적
기존 수면 연구는 주관적 설문 의존 또는 고가의 수면다원검사(PSG)로 샘플 수가 극히 제한적이었다. 정보학적 방법론(RESTful API + 웹 크롤링)으로 이를 보완하고, 타 파트(생명공학·뇌과학·약학·정책)의 다학제적 결과를 결합하는 통합 데이터 플랫폼 **Chrono-Twin**을 설계한다.

## 데이터 수집 파이프라인 (하이브리드)
- **오픈 API 기반 생체 데이터**: 웨어러블 제조사(Fitbit, Apple HealthKit) 개발자 API를 OAuth 2.0 인증으로 연동 → 수면 세션 데이터(수면 단계, 렘수면 비율, 심박수 변화) 주기적 수집. Fitbit Web API로 Python 자동 풀링 구조 설계.
- **PhysioNet Sleep-EDF 데이터셋**: 초기 데이터 부족 문제 해결용 표준 수면 패턴 모델 학습.
- **웹 스크래핑 엔진**: Python Selenium으로 교육·생활 커뮤니티 게시글에서 '수면 부족', '피로', '에너지 드링크', '늦잠' 키워드 추출 → 타임스탬프 분석으로 야간 활동 집중도와 수면 지연 상관관계를 텍스트 마이닝.

## 데이터 수집 스키마 (6개 필드)
| 필드명 | 타입 | 설명 | 소스 파트 |
|---|---|---|---|
| user_id | String (UUID) | 고유 사용자 식별자 | 시스템 자동 생성 |
| sleep_onset | Timestamp (ISO 8601) | 실제 취침 입면 시간 | 오픈 API / 설문 |
| sleep_wake | Timestamp (ISO 8601) | 실제 기상 시간 | 오픈 API / 설문 |
| caffeine_intake | Float (mg) | 당일 카페인 총 섭취량 | 약학 파트 |
| bluelight_duration | Integer (min) | 취침 전 2시간 내 스마트폰 노출 시간 | 생명공학 파트 |
| brain_peak_score | Float | 뇌과학적 인지 기능 최고점 시간대 | 뇌과학 파트 |

추가 필드 예시: sleep_duration(총 수면 시간), sleep_efficiency(수면 효율 = 실제 수면 시간 / 침대에 누운 시간 × 100).

## 데이터 정제 알고리즘
- **결측치 처리**: KNN(K-Nearest Neighbors) 이미테이션 — 유사한 수면 위상 그룹의 평균값으로 보정. (여유가 있을 때 진행)
- **이상치(Outlier) 제거**: Z-Score 판별식. 평균 μ, 표준편차 σ일 때 `|Z| = |X − μ| / σ > 3.0` 인 데이터는 분석에서 제외.
  - 적용 변수 범위: 블루라이트 0~480분, 카페인 0~1,000mg, 수면 부채 0~3,000분, 취침 시각 지연 ±180분.

## MCTQ 기반 MSFsc 알고리즘
수면 위상을 결정하는 가장 유의미한 지표는 휴일의 중간 수면 시각(MSF). 그러나 주중 누적 수면 부족으로 주말에 과도하게 자는 **수면 부채(Sleep Debt)** 현상 때문에 보정이 필요.
```
MSF   = 수면 개시 시각(주말) + 수면 지속 시간(주말) / 2
MSFsc = MSF − (SDf − SDw) / 2
```
- SDw = 주중 평균 수면 시간, SDf = 주말 평균 수면 시간
- MSFsc 값이 클수록(늦을수록) 수면 위상이 더 뒤로 밀린 것.
- 모듈에서는 `calcSleepDebt()` 함수로 이식. 5일치 실제 수면 시간(h) 입력 → 일별 `max(0, 480 − 실제 수면 분)` 계산 → 누적 합산 → β₃×debt 회귀 항 산출.

## 수면 부채 누적량 (X₃) 계산
```
일별 수면 부족량 = MAX(0, 480분 − 당일 실제 수면 시간)   (권장 수면 8시간 = 480분)
X₃ = (D-1 부족량) + (D-2 부족량) + ... + (D-5 부족량)
```
예: 직전 5일간 7h, 6h, 6.5h, 7.5h, 5h 수면 → 60+120+90+30+180 = 480분 부채.

## 통계 분석 (고등학생 수준)
1. **기술통계**: Y·X₁·X₂·X₃의 평균·표준편차·최솟값·최댓값. Shapiro-Wilk 정규성 검정(표본 < 50). 히스토그램·박스플롯.
2. **상관분석(사전 탐색)**: 피어슨 또는 스피어만 상관계수. 상관행렬 히트맵으로 다중공선성 예비 점검(X 변수 간 r > 0.8이면 통합 처리 검토).
3. **다중선형회귀(메인)**:
   - 단순 모형 3개 (X₁만 / X₂만 / X₃만) → 개별 R²·β·p-value
   - 통합 모형 (X₁+X₂+X₃ 동시 투입) → 전체 R²·조정 R²·표준화 β*
   - 단계적 회귀 (p > 0.1 변수 제거) → 최적 예측 변수 조합
   - VIF 점검 (< 5 권장, < 2 이상적)
4. **분석 도구**: 1차 엑셀 '데이터 분석' 추가기능(팀 전원), 2차 Google Colab Python (pandas + statsmodels, 이정욱 담당). JASP도 SPSS 대체 가능.

## 결과 해석 기준
| 지표 | 기준값 | 해석 |
|---|---|---|
| p-value | < 0.05 | 해당 변수가 수면 위상 지연에 유의미한 영향 |
| R² | 0.3 이상이면 의미 있는 설명력 | 모형이 지연의 몇 %를 설명하는가 |
| 표준화 β* | 절댓값 클수록 영향력 강함 | 세 변수 중 상대적 영향력 순위 |
| VIF | < 5 (엄격: < 2) | 다중공선성 없음 |
